# WyrdDebug
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

On-demand inspector document. Not saved, and not rebuilt each frame.

[`snapshot`](#snapshot) reads the live runtime. An empty section list builds every section in [`SECTIONS`](#sections). A named list builds only those sections. `prefix` is applied while each section collects rows: a row is kept when its `key` begins with that text, and a fact row is also kept when its `fact` does. Kept rows are then sorted and paged. `offset` and `limit` page those rows. `limit` of 0 returns the rest. One `debug_snapshot` line is logged when tracing is on. Deed, social, and precedence reads use the witness and time-bucket indexes. One `deed_index` line is logged per section when tracing is on. Turning deed lookup off walks every row and does not log that line.
