# WyrdProposal
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

One unsaved pick, cast, and bind result.

[`id`](#id) is `p<seq>`. The sequence resets on a new game and on load. [`casts`](#casts) maps a cast slot to the picked entity. [`params`](#params) maps a param to `{entity, kind}`, plus `owner` for an item and `place` for an item or object when a spatial adapter is registered. The payload is not readable by content.
