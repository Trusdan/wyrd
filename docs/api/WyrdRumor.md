# WyrdRumor
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Precise rumor hops and coarse reach.

A deed starts a rumor when it carries a reveal claim and the first registered policy matches its verb. Origins are the actor and that row's witnesses. That slice is the witness index for the deed, so this does not scan the log. Each origin offers the claim to sorted [`WyrdSocial.targets`](WyrdSocial.md#targets) of the policy kinds. A listener is queued once, from the earliest speaker. The hop rolls [`WyrdRng.for_decision`](WyrdRng.md#for_decision) on stream `rumor`. The decision key is `deed, from, to, hop`. The time bucket is the hour bucket of `now`. Adoption uses the credibility score and threshold, and writes `believed/<listener>` only. A listener in a coarse place does not adopt and does not pass the claim on. Empty places count as precise. A deed in a coarse place stores a reach row instead of hops. Each coarse tick enqueues one rumor unit that raises that row's level by one. [`materialize`](#materialize) rolls once when content asks about one NPC there. An accepted hop or materialize then evaluates [`WyrdRumorPolicy.mutations`](WyrdRumorPolicy.md#mutations) on the claim value. The listener stores that copy. The deed row is unchanged. Jobs, the seen set, the queued set, reach rows, the once-set, and those copies are saved in `flight.rumor`. Mutation callables are not. Load rebinds them from the registered policy with the same id. A job or reach row whose policy is not registered is `push_error` and that deed's in-flight state is left out. Beliefs already written stay.

### `materialize`

**Experimental**

```gdscript
func materialize(who: StringName, key: StringName) -> void
```

Rolls once for the lowest undrawn reach row at `who`'s coarse place. An accept writes `believed/<who>`. A reject is also once. Level 0 does not roll. An existing belief is left as it is.

### `REACH_FULL`

**Experimental**

```gdscript
const REACH_FULL = 4
```

Level at or above this is a certain materialize roll, because `randf` is below 1. Chance is `level / REACH_FULL`. Level 0 does not roll.
