# WyrdTickQueue
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Per-tick work list for waiting conditions.

A fixed budget, from [`WyrdConfig.scheduler_work_per_tick`](WyrdConfig.md#scheduler_work_per_tick), re-checks dirty indexes in ascending order. The rest stay dirty. The sort is taken once per [`tick`](#tick) call. A mark during that call joins the next call, still in ascending order. Which indexes are watched is rebuilt from the content index. The dirty set is saved.
