One rumor rule. The host registers it from code. It is not saved.

[`kinds`](#kinds) are directed relationship kinds. [`max_hops`](#max_hops) is how many steps the claim may travel from an origin. An empty [`verbs`](#verbs) list matches every deed verb. [`pass_chance`](#pass_chance) is the seeded chance that a hop is offered. `1` always offers it. `0` never does. [`mutations`](#mutations) is an array of dictionaries. Each one has `field` (the claim fact key), `to` (a callable or `drop`), and `keep_chance_fn`. There is no `.wyrd` syntax for a policy.
