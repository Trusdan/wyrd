# WyrdRpnEval
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Stack evaluator for a [WyrdCompiledCondition].

Seed of the S2 evaluator. `funcs` maps a function name to a [Callable] that receives the argument array. A missing fact makes a comparison false. Load-time caches, when added, are rebuilt from the saved plain data and are never written back. [`WyrdCompiledCondition.code`](WyrdCompiledCondition.md#code) keeps the documented opcodes.
