# WyrdSceneRunner
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Walks one open scene. The facade exposes this as `Wyrd.dialogue`.

Line text is always emitted. `line_audio(line_id, locale)` may return null and never hides text or advances a line. [`advance`](#advance) is the only way past a line. [`choose`](#choose) runs the choice effects, then diverts. `-> scene` calls a sub-scene and returns. [`abort`](#abort) runs `on_abort` from the inside out. [`can_save`](#can_save) is false while a scene is open. A bound holder who dies, or whose slot holder changes, aborts with `holder_died` or `holder_left`. A choice effect, or a scene-line effect, that changes this scene's own holder does not abort it. Its remaining lines keep the speakers bound when the scene opened. Every other open scene still aborts. [`open`](#open) lists unlocked topics with an eligible storylet. [`ask_topic`](#ask_topic) runs that storylet. A line or set emits [`topic_answered`](#topic_answered).
