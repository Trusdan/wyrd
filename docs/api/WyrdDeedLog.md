# WyrdDeedLog
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Deed log with hour-bucketed decay. [`compact`](#compact) merges interchangeable rows.

Rows are parallel packed arrays. Indexes are by actor, target, and verb. A witness index stores each witness once per deed. That witness is the knower of the deed. `saw`, `heard`, and `inferred` share the list. The mode stays on the row. A believer index stores each rumor listener who adopted the deed, with the minute they adopted it. [`note_believer`](#note_believer) keeps the earlier minute. Time buckets use [`WyrdConfig.hour_bucket_minutes`](WyrdConfig.md#hour_bucket_minutes). Each row is stored once. [`set_lookup`](#set_lookup) false makes scans walk every row instead. The witness index and the time index are not saved. The believer index is rebuilt from the optional `believers` field on each deed row. `now` is bucketed with [`WyrdConfig.hour_bucket_minutes`](WyrdConfig.md#hour_bucket_minutes). Memorable rows keep full magnitude. A half-life of 0 does not decay. Sums are rounded to 6 decimal places before they are returned. Witnesses `auto` ask [`WyrdSpatialAdapter.witnesses_of`](WyrdSpatialAdapter.md#witnesses_of). An explicit list is stored as given, sorted by id. Each witness stores a perception mode from [`WyrdSpatialAdapter.perceive`](WyrdSpatialAdapter.md#perceive): `saw`, `heard`, or `inferred`. An empty mode drops that witness. A rumor adoption is not a witness. It is a believer.

### `compact`

**Experimental**

```gdscript
func compact() -> int
```

Merges rows that still count the same, and drops weight that has rounded to zero. Rows keep their minute, so a `within` window does not grow. The newest id in a merged group is kept. Believers from a merged group move onto that id, and the same listener keeps the earlier minute. A dropped row loses its believers. `_next` does not go backwards. Perception callbacks do not run.
