# WyrdAIPacket

**Experimental**

Inherits: `RefCounted`

Context packet for one opted-in line. Static builders only.

Facts are the `ai_context` keys the player knows, with the known value. A fact the player has not learned is left out, including every resolved fact. Facts carry no secrecy name and no public marker, so a world value the player does not know never enters the packet.
