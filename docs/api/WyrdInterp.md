# WyrdInterp
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Turns a prose line's raw interpolation spans into a small tree.

`{expr}` is a value. `{if}...{else}...{end}` is a conditional fragment and may nest. `{holder(name)|variants}` marks a holder switch. The runtime picks a variant line, or the name-free line. `else` and `end` are reserved only as whole spans.
