# WyrdHash
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Stable FNV-1a 64-bit hash for [StringName] values and ints.

Godot's `@GlobalScope.hash` is not used. The engine does not promise that `hash()` stays the same across versions or platforms, and a [StringName] hash can follow the intern table rather than the characters. Save keys, per-decision seeds, and determinism tests need a hash that is only a function of the bytes.  The result is the unsigned 64-bit FNV-1a value stored in a signed 64-bit int (the GDScript [int] is signed, and arithmetic wraps modulo 2^64, which is the FNV step).  Domain bytes keep the kinds of input apart: `0x01` then the UTF-8 bytes of a [StringName] or of [`of_text`](#of_text), `0x02` then an int as eight little-endian two's-complement bytes, or `0x03` then those same eight bytes folded onto an existing hash by [`combine`](#combine). [`of_text`](#of_text) does not intern the string and does not use the short-name memo.
