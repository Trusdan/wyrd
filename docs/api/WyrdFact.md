Inherits: `RefCounted`

One declared fact key or key pattern.

[`origin`](#origin) is `stored` or `resolved`. [`invalidate`](#invalidate) is empty, `on_event`, `poll`, or `per_query`. [`recap`](#recap) keeps provenance for a concrete stored fact when deeds compact. [`recap_marked`](#recap_marked) is true when the source wrote `recap:`, including `false`. Pattern segments are stored as `{name}`.
