# WyrdLineDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdStmtSpan`

One spoken line or journal entry.

[`kind`](#kind) is `spoken`, `journal`, `storylet`, or `variant`. [`tags`](#tags) holds names from `#tag:`. `voiced` is the recording tag. [`variant_slot`](#variant_slot) is the `holder()` argument on this line. [`variants`](#variants) are the pre-written holder lines. [`holder`](#holder) is set on a variant line. [`scene_id`](#scene_id) is empty on a journal entry.
