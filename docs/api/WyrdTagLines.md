# WyrdTagLines
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Writes missing `#line:` ids. The only command that edits source.

Ids are lowercase hex from [WyrdHash] and [WyrdRng], four characters, longer on a pack collision. An existing id is never changed. Every other byte stays, including indent, comments, and CRLF. A second run changes nothing.
