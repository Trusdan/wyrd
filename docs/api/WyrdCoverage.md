# WyrdCoverage
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Hit counts for storylets, slot variants, and line ids.

Recording is off until [`enabled`](#enabled) is set. A release build does not turn it on. Counts are not part of a save. [`merge`](#merge) adds them to a JSON file, then clears the in-memory delta. The default file is [`DEFAULT_PATH`](#default_path).
