How one cast slot or param splits its top-level `and` clauses.

Not exported, not saved, and not part of a golden or cross-reference dump. [`scan`](#scan) uses the full candidate walk. Otherwise each clause is `scope`, `pin`, `local`, or `rest`. [`key`](#key) is the host filter plus the local clauses, so the same shape shares one cache. A second pin is stored as `rest`.
