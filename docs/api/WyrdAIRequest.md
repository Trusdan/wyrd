# WyrdAIRequest

**Stable**

Inherits: `RefCounted`

One AI request. The answer comes back later through [`reply`](#reply).

The owner is a [Callable] set by [WyrdAI]. The request does not keep the runtime.

### `owner`

**Stable**

```gdscript

```

Empty for a host request. `scene:<root scene id>` for a scene prefetch. `topic:<npc>` for a topic prefetch. `bark:<storylet id>` for a bark prefetch. `summary:<quest id>` for a journal summary. Not part of the cache key.

### `sent_minute`

**Stable**

```gdscript

```

Game minutes when the request was sent. `-1` until then. Not part of the cache key. Bark and summary expiry read it.
