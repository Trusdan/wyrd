# WyrdOpcodes
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Flat instruction set for a compiled condition.

`and`, `or`, and `?:` are jumps, not opcodes. `LOAD_FACT` loads one const key. `LOAD_KEY` joins `n` segment values already on the stack. `CALL` is a name const then an argument count. `IN_RANGE` is inclusive. `IN_SET`'s operand is the element count. `MAKE_SET`'s operand is the element count. It leaves the set on the stack.
