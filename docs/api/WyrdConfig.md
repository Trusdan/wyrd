### `ai_max_inflight`

**Stable**

```gdscript

```

The most requests Wyrd itself keeps open at once for prefetch. `0` or less turns Wyrd's prefetch off. Requests the host sends through [`WyrdAI.request`](WyrdAI.md#request) count toward it but are never refused by it. Read at each prefetch. Not saved.
