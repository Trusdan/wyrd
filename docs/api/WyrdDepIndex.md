# WyrdDepIndex
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Fact-key to condition-index map, built from compiled reads.

Condition identity is the index passed to [`build`](#build). Exact keys live in [`exact`](#exact). A read with a `{...}` segment is a pattern: it is stored by segment count and static prefix, and a changed key matches only when every segment agrees. The prefix is a lookup bucket. The condition still depends on the whole pattern, so a computed segment (`LOAD_KEY`) is never resolved here. Rebuilt from plain reads. Never saved.
