# WyrdAIValidator
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Five checks for one delivered string. Pure: no runtime and no resolver.

[`check`](#check) returns the first failing rule, or an empty name when the text passes. The order is limits, names, banned, spoiler, classifier. The text is never edited.
