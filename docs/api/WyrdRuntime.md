# WyrdRuntime
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

One narrative runtime. Tests each keep their own instance.

S2a loads a manifest by compiling its `.wyrd` sources, then keeps a fact store, a condition table, and a fixed-work scheduler. S2b adds the deed log, relationship axes, and role slots. S2c runs slice effects, quests, and scenes. S2d saves that state and can record a decision trace. Callables stay in the registries.
