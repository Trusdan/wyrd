# WyrdStoryletDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdStmtSpan`

One compiled storylet. [WyrdDirector] ranks these at runtime.

[`generic`](#generic) is true when `when` was omitted. [`specificity`](#specificity) counts top-level `and` clauses. [`body_kind`](#body_kind) is `line`, `set`, or `scene`. [`cooldown_minutes`](#cooldown_minutes) is stored here. The director enforces it. [`speaker_cooldown_minutes`](#speaker_cooldown_minutes) is a bark clock for one concrete speaker. [`priority`](#priority) is stored and does not change [`specificity`](#specificity).
