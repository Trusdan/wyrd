# WyrdFactXref
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Fact cross-reference for one pack (WFR1).

Readers and writers reuse [WyrdDepIndex] pattern rules. `record deed` is a fact write only when it has `reveals`. Resolved facts are never "never set". Fact defaults are not in the grammar yet, so a stored fact that is read and not written has no default. [`events`](#events) records `on_event` names (`role` `invalidate`) and `on <event>` handlers (`role` `emit`). A scene `learn` warns `W_STALE_BELIEF` when a contradicting belief remains. Prose may interpolate a belief or a held value as `W_CLAIM`. A world value behind a world gate is `E_FACT_LEAK`. A stored `set` or `inc` in a stage that sets an outcome, or on a choice, warns `W_RECAP_UNMARKED` when that fact has no `recap:` key.
