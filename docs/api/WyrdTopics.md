# WyrdTopics
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

The player's unlocked topic ids.

There is no topic declaration. An id is whatever `unlock topic`, `lock topic`, or `scope: topic` uses. A repeat unlock traces `already` and does not signal again. A lock of a topic that is not unlocked traces `not_unlocked` and does not warn. The save bag is a sorted id list, omitted when empty. Unknown ids are kept.
