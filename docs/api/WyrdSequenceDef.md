# WyrdSequenceDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

Inherits: `WyrdStmtSpan`

One timed event sequence (WFR15).

[`mode`](#mode) is `ordered` or `any`. [`need`](#need) is how many matches finish it. [`total`](#total) is the cap. [`within_minutes`](#within_minutes) is the window in game minutes. [`reset_event`](#reset_event) is a declared event name. [`reset_cond`](#reset_cond) is used when the reset is not a bare event. [`steps`](#steps) are match-only `on` handlers.
