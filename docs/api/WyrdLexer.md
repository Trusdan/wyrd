# WyrdLexer
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Lexer for grammar v1 sections 1–6.

Indentation is two spaces. A tab is `E_TAB_INDENT`. Indent may rise by one level at a time. Blank lines and comment-only lines are ignored. Inside a `facts`, `events`, `role`, `sequence`, `storylet`, `document`, or `template` block, lines stay code. The lines of a `page` block are prose, like dialogue. A `when <cond>:` prefix on those lines stays code up to the first colon at depth 0. A storylet prose line starts with a dash. A dash before `(` stays a label. Elsewhere a line that starts with an identifier and a colon is prose: `{{` is a literal `{`, a single `{` opens an interpolation raw span, and a stray `}` is literal. `}}` is not an escape. Draft statement syntax, not a grammar v1 change: `on_empty`, `on_missing_stage`, `on_abort`, and `requires` stay code when they open with a colon. A `when <cond>: <speaker>:` line keeps the condition in code and the spoken text in prose. The first depth-zero `: <speaker> :` ends that condition, so a ternary colon in it needs parentheses. `variant <holder>:` is prose after the colon. `#tag:<name>` and `#secrecy:<name>` may sit before `#line:`.
