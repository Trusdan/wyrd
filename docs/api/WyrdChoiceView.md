# WyrdChoiceView
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

One choice the host should show.

A choice whose condition is false is omitted. [`enabled`](#enabled) is false when `show_disabled_when` is true, and [`reason`](#reason) is the quoted reason. [`check`](#check) is the skill id, empty when the choice has no check. [`check_args`](#check_args) is evaluated when the choice is presented. A hidden or disabled choice never calls the skill adapter. [`index`](#index) is the position in this presented list. [`WyrdSceneRunner.choose`](WyrdSceneRunner.md#choose) uses that index.
