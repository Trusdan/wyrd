# WyrdText
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Renders compiled prose and the default journal date.

Interpolation runs at display time. A missing value renders as `{?<expr>}`, not an empty string. `0` stays `0`. A `{holder(name)|variants}` span is removed here. The runtime picks the variant line before render, or leaves this name-free text. A line with no spans is walked and then passed through `TranslationServer.translate` with the line id as context. A line with spans looks up [`WyrdLineDef.template_of`](WyrdLineDef.md#template_of) the same way. A translated template is compiled, and it renders when its placeholders match. Otherwise the source line renders, Godot logs a warning, and a `text_translate ok=false` trace row explains why. The default date is `day N, HH:MM` from game minutes, day 1 at minute 0, 1440 minutes per day. A host formatter replaces it for new text.
