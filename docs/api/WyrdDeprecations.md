# WyrdDeprecations

**Experimental**

Inherits: `RefCounted`

Ids that warn once at runtime.

One row per id. `kind` is `call` or `keyword`. `diagnostic` is the compiler code, or empty for a call. [`warn_once`](#warn_once) pushes one warning per id and adds no trace row.
