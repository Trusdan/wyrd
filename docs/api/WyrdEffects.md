# WyrdEffects
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Runs the slice effects, including belief and knowledge writes.

`set` and `inc` write stored facts and keep provenance `scene`, `choice`, and `time` (game minutes). A `do` failure returns its `on_fail` target: a label in a scene, or a stage in a quest. Set literals in deed arguments are read from the stored argument text, because the expression emitter does not push a set value. `start_quest` and `advance` call [`WyrdQuestRunner.start`](WyrdQuestRunner.md#start) and [`WyrdQuestRunner.advance`](WyrdQuestRunner.md#advance). `assign_role` and `vacate_role` call the content role entry points. `adjust_baseline` calls [`WyrdSocial.adjust_baseline`](WyrdSocial.md#adjust_baseline). `unlock_topic` and `lock_topic` call [WyrdTopics]. A repeat unlock does not emit [`topic_unlocked`](#topic_unlocked) again. Out-of-slice effects cannot appear here; the compiler rejects them.
