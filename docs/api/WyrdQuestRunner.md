# WyrdQuestRunner
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Quest status, stages, waits, variants, outcomes, and the journal.

`start when` and `waits_until` advance only after the tick queue has re-checked them. A stage that names a scene offers it; the host opens it, and transitions wait until that scene ends normally. An aborted scene stays pending. The winning slot variant replaces the stage body. `unwilling` and `barred` are evaluated live and again on a tick when no scene or host step is open. Ending a scene finishes the current body before that re-check. `route_closed` does not finish the quest. The quest completes when every declared outcome is `done` or `failed` and the current body has no transition. Any `failed` outcome fails the quest instead. [`start`](#start) ignores `start when`. [`advance`](#advance) leaves through the same path as a transition, including a stage that is still waiting. `on_empty: wait` holds a stage when a slot is empty and no variant matched. Journal text and its date are frozen at the write. The default date is `day N, HH:MM`. [`summary`](#summary) returns the frozen journal entries joined in order, or validated cached summary text, and does not write the journal. An `await_host` step calls [`request_host_step`](#request_host_step) and pauses the remaining entry steps until [`complete_host_step`](#complete_host_step). A stage may name parallel `region` blocks. Their active leaves are saved on the quest row and omitted when the stage has none.

### `start`

**Experimental**

```gdscript
func start(quest_id: String) -> void
```

Starts `quest_id` whatever its `start when` says. `dormant` and `available` become `active` at the first stage, through `_consider_start` and `_activate`. `active`, `completed`, `failed`, and `abandoned` warn and stay. `unavailable` stays `unavailable`. A running step list is already `active`, so a start of that quest warns and does not defer.

### `advance`

**Experimental**

```gdscript
func advance(quest_id: String, stage_id: String) -> String
```

Moves an `active` quest to a top-level stage through `_goto`. `waits_until` and a held-empty wait do not block it. The offered scene and the waiting reason are cleared. A pending host step or an open scene for this quest warns and stays. The current stage is a no-op. Any other status warns and stays. When both a host step and a scene are open, the reason is `host_step`. A quest whose own step list is running applies the move after that list, like a divert. The returned stage id is that divert. Other callers get an empty string.

### `expire_due`

**Experimental**

```gdscript
func expire_due(now: int) -> void
```

Abandons generated instances whose `expires:` has elapsed. An open scene of that instance waits for the next tick. Hand-written quests are skipped. This does not call [`abandon`](#abandon), so another open scene stays up.
