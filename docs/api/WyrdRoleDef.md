# WyrdRoleDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdStmtSpan`

One compiled role definition.

Built from a top-level `role` block, or from the same field strings [`WyrdRoles.define`](WyrdRoles.md#define) accepts. [`CANDIDATE`](#candidate) is the entity under test inside [`eligibility_text`](#eligibility_text). Omitted eligibility accepts every entity. [`strategy`](#strategy) `relation` and `none` run at vacate. Other stored strategies do not run yet.
