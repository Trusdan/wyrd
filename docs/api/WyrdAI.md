# WyrdAI
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

AI hook for one runtime. Open requests are not saved.

The null provider is the default. A request keeps no pending state while that provider is active, or while the hook is disabled. [`deliver`](#deliver) closes a pending request, validates the text, and caches it when it passes. [`present`](#present) shows that cached text for an opted-in line when the provider lists the current locale. Otherwise the authored line shows. Dialogue does not wait. The cache is saved only when [`WyrdConfig.ai_save_cache`](WyrdConfig.md#ai_save_cache) is true and it is not empty. [`packet_for_line`](#packet_for_line) builds a packet without sending. [`kind_for_line`](#kind_for_line) is `gossip` when the line is opted in and tagged `gossip`. [`summary_for`](#summary_for) returns a journal summary. [`host_text`](#host_text) reads cached text for a host-called kind and does not send.
