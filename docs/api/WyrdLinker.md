Links one pack: symbols, line ids, commands, and the fact cross-reference.

Files are already sorted. Diagnostics are added to the shared collector; [WyrdPack] sorts them. An `unlock topic` or `lock topic` with no `scope: topic` storylet warns `W_TOPIC_NO_STORYLET`.
