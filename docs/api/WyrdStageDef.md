# WyrdStageDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdStmtSpan`

One quest stage, or the statement body of a variant.

[`scenes`](#scenes) entries are `id`, `with`, and a span. [`hosts`](#hosts) entries are `screen`, `fields`, and a span. [`transitions`](#transitions) entries are `target`, `when`, `expr`, and a span. [`variants`](#variants) holds [WyrdVariantDef] records. The array is untyped so the stage and variant records can name each other.
