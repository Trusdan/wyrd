# WyrdContent
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Runtime index of one compiled pack. Built at load. Not a save document.

Quests, scenes, storylets, and lines are the compiler's plain records, keyed by id. A storylet `when` is compiled and is not added to the tick queue. [`conditions`](#conditions) is every gating condition, in source order, with a parallel [`records`](#records) / [`sites`](#sites) pair. `chance` uses `<record>:<site>`. [`manifest_hash`](#manifest_hash) folds the pack id and each unit hash with [`WyrdHash.combine`](WyrdHash.md#combine), paths sorted. When [`aliases`](#aliases) is not empty, it also folds [`alias_text`](#alias_text).
