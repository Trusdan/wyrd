# WyrdDocuments
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Readable documents: open, frozen copies, and read flags.

Read flags are a set of `(reader, doc_id)` pairs. They are not stored facts. `Wyrd.facts`, the fact schema, the `W_FACT_*` lints, the facts export, and the snapshot `facts` section do not see them. [`has_read`](#has_read) is the query. The save bag is `documents`. A copy stores page and paragraph visibility, each `{if}` as a boolean in walk order, and each value with [`WyrdSave.pack_claim`](WyrdSave.md#pack_claim). It does not store rendered strings.
