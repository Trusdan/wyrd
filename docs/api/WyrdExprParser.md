Recursive-descent parser for one expression.

Precedence, loosest first: `?:`, `or`, `and`, `not`, comparisons and `in`, `+ -`, `* /`, unary `-`. `fact(...)` is a fact reference. `[a, b]` is a set. `6..18` is a range.
