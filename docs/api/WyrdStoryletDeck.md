# WyrdStoryletDeck
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Seeded draw of a storylet line set, plus director selection rows.

[`draw`](#draw) does not record a selection. [`note_selected`](#note_selected) does. A known draw notifies [`on_coverage`](#on_coverage) with the storylet id and the line id. A `visible` callback can skip a line. The cursor moves past a skip. A `line` body and a `scene` body write no draw row. A `set` shuffles with [`WyrdRng.for_decision`](WyrdRng.md#for_decision) on the [`STREAM`](#stream) stream, the storylet id, and the cycle number. The row stores that order, a cursor, and the cycle. The next cycle starts when the cursor reaches the end. `seen` and `last_minute` ride on the same row and are omitted when the storylet has never been selected. An id the pack does not declare is kept and ignored. Bark speaker clocks live in a separate bag, `bark_speakers`.
