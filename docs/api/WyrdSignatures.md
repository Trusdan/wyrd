# WyrdSignatures
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Typed signatures for condition built-ins, plus host pure functions.

[`register`](#register) matches the compiler side of `Wyrd.register_function`: a name, positional parameters, and a return type. There is no callable here. `knows` reads what an agent knows. `known` was removed; compiling it reports `E_KNOWN_REMOVED`. `believes` is the truthy belief. `belief` reads the value; its declared return is only the fallback for a dynamic key, and the checker uses the fact's type. `conflicted` is the WFR9 group-position check. The M4 slot state stays `contested`. `perceived` returns the latest `saw`, `heard`, or `inferred` mode, or null.
