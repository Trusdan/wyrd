Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

One line ready for the host to show.

[`text`](#text) is always set. [`audio`](#audio) comes from `line_audio` and may be null. Audio never replaces the text and never advances the line.
