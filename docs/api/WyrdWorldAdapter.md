### `reports_changes`

**Stable**

```gdscript
func reports_changes() -> bool
```

Default is false. This is a default, not an unimplemented stub, so it does not `push_error`. A host that returns true promises to call [`Wyrd.invalidate_world`](Wyrd.md#invalidate_world) whenever an entity is added or removed, or its kind, tags, liveness, attributes, or [`candidates`](#candidates) membership change.

### `candidates`

**Stable**

```gdscript
func candidates(filter: WyrdEntityFilter) -> PackedStringArray
```

Entity ids that match `filter`. An empty kind and tag means every entity the host is willing to offer. Order is not significant. Role casts pass an empty filter. Object and item casts set [`WyrdEntityFilter.kind`](WyrdEntityFilter.md#kind) and [`WyrdEntityFilter.tag`](WyrdEntityFilter.md#tag). Items use kind `item`. When [`reports_changes`](#reports_changes) is true, Wyrd may reuse an earlier answer until the next [`Wyrd.invalidate_world`](Wyrd.md#invalidate_world).
