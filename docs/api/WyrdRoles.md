# WyrdRoles
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Role bindings and the quest-slot subset.

A binding holds `holder`, `since`, `status` (`default`, `successor`, `empty`, `contested`), and `history`. [`assign`](#assign) is host setup for the default holder. [`define`](#define) stores the same fields as a `role` block. [`eligible`](#eligible) tests `candidate`. [`vacate`](#vacate) runs `relation(...)`, `faction_assigns(...)`, `host_decides`, and `election`. `election` and `host_decides` leave the role `contested` until [`assign`](#assign). `vacancy: abolish` runs when a strategy finds nobody. `live` follows the role. `locked_at` freezes in [`enter_stage`](#enter_stage). `cast` picks once in [`begin_quest`](#begin_quest) from [`WyrdWorldAdapter.candidates`](WyrdWorldAdapter.md#candidates) and freezes that entity. A slot with `kind: object` or `kind: item` passes that kind and the `has_tag` symbol to `candidates`, freezes the pick, and resolves only `locked_gone`, `empty`, and `default`. An item pick also stores `owner` when an inventory adapter is registered. Slot state `hostile` means disposition toward `player` is below the threshold. Precedence is `locked_gone`, `contested`, `empty`, then `barred`, `hostile`, `unwilling`, `successor`, and `default`. The first of those with a declared variant on the current stage wins. `contested` with no variant uses the `empty` variant and stays `contested`. `locked_gone` is a frozen `locked_at` holder who was vacated or is not alive. A departure whose history reason is `assign` is not a vacate, whether the host or content assigned the new holder. A secret holder's key `role.<id>.holder` is in `known/` only for agents passed to [`tell`](#tell).
