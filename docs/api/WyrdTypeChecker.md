# WyrdTypeChecker
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

Inherits: `RefCounted`

Type-checks one expression against a fact schema and function signatures.

`int` widens to `float`. A bare name satisfies `symbol` or `entity` from the parameter that expects it. `m` is minutes or metres only when that parameter expects a duration or a distance.
