# WyrdTrace
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Debug record of host answers and Wyrd decisions.

Turn [`enabled`](#enabled) on before play. [`replay`](#replay) drives the recorded inputs (`open_scene`, `advance`, `choose`, `abort`, `tick`, `emit`, `complete_host`, `draw`, `batch_begin`, `batch_end`, `emit_rejected`, `open_document`, `create_copy`, `ai_deliver`, `quest_summary`, `ai_host_request`, `host_call`) on another runtime. Host answers and decisions are compared with [`diff`](#diff). A different host answer shows up there.

### `prefix`

**Experimental**

```gdscript
var prefix: String = ""
```

When set, a line is kept when its quest, role, slot, who, key, scope, speaker, path, or instance equals this text or begins with it. Empty keeps every line. Belief, knowledge, credibility, event witness, and evidence lines use who and key. A credibility line's who is the listener. An evidence line's who is empty. A director line and a why_not line use scope, speaker, and key. Key is the scope id. A director_candidate line uses the same fields. Its path is the storylet id. A region line uses quest and path. A quest_start, quest_advance, or quest_status line uses quest. Replay skips them. Load does not log them. A role_assign or role_vacate line uses role. A baseline_adjust line uses who, which is a. Replay skips them. Load does not log them. A sequence line's key is the sequence id. A voice line's key is the name-free line id, and its who is the holder. A secrecy line's key is the storylet id, or the line id when there is no storylet. Its path is the line id. The prefix matches either. A debug_snapshot line is one inspector read. key is the caller prefix. path is the section list, or * when every section was requested. The prefix matches key or path. Load does not log one. Replay skips it. A choice_summary line is one provenance read. key is the key prefix. path is the scene filter. A choice_compact line is one provenance drop. Its path is the dropped keys, joined by commas. Replay skips both. A coverage line is one recorded hit. hit is storylet, line, or variant. key is the id. path is the source file. A coverage_report line is one never-hit read. Replay skips both. A console line is one playtest command. path is console. key is the target. role is set for kill, vacate, and replace. source is console. Replay skips it. Load does not log one. A deed_index line is one snapshot read of the witness or time-bucket index. scope is deeds, social, or precedence. key is the caller prefix. ids is the deed-row count, or the agent-name count for precedence. Replay skips it. Load does not log one. Lookup off does not log one. A gen_create line is one generated instance. template is the template id. instance is `<template>#<n>`, or empty when creation was refused. n is the new counter, or 0 when nothing was created. ok is true or false. reason is created, unknown_template, bad_cast, or bad_param. Replay skips it. Load does not log one. A gen_offer line is one queued or replaced story-pressure offer. source is host or deed. key is the offer key. tier may be empty. origin is host or deed. template is empty for a host offer. queued is the queue length after the change. replaced is true or false. The record also stores payload. The printed line does not. The prefix matches key or template. A host-origin row is a replay input and calls [`WyrdGenerator.offer`](WyrdGenerator.md#offer). A deed-origin row is skipped, because the replayed deed queues it again. Load does not log one. An ai_provider line is one provider registration or one enabled change. id is the provider id. state is on when the hook is enabled and the provider is not the null provider. An ai_request line is one request call. id is the request id, or 0 when it was refused. path is the line id. state is sent or refused. reason is -, kind, off, or null. An ai_result line is one deliver call. ok is true or false. rule is -, late, unknown_request, or thread. An ai_cancel line is one pending request removed without a delivery. reason is host, provider, off, new_game, load, scene_end, superseded, or expired. The printed kind is stored as slot_kind. An ai_deliver row is a replay input: it calls [`WyrdAI.deliver`](WyrdAI.md#deliver). It is recorded and not printed. A provider that answers inside `request` records that row during the input that sent it, so replay delivers it only after that input returns. Lines shown during that input can then differ. A provider that answers on a later frame replays the same text. A `quest_summary` row calls [`WyrdQuestRunner.summary`](WyrdQuestRunner.md#summary). An `ai_host_request` row calls [`WyrdAI.request`](WyrdAI.md#request). The request kind is stored as `slot_kind`, because `kind` is the event name. With those rows a replay sends the same requests with the same ids, so each recorded `ai_deliver` answers the right request. ai_prefetch, ai_use, ai_late, and ai_sweep are skipped, like the other ai rows. An ai_sweep line is one bark sweep armed or dropped. op is arm or drop. reason is start, change, floor, off, provider, new_game, or load. Load does not log them. The prefix matches path. A gen_tier line is one eligibility pass. eligible is the template count. A gen_pick line is one weighted pick. score is `<priority>/<specificity>`. band is the top-band size. seed_key is the decision key. template is empty and reason is no_template when nothing is eligible. Replay skips both. Load does not log them. A gen_candidates line is one host candidate list, sorted, before the cast condition. count is that list. digest is the [WyrdHash] of those ids. key is the decision key. A gen_cast line is one cast slot on a proposal. A gen_bind line is one param. Replay skips them. The accept that follows logs the existing cast and gen_create lines. A gen_propose line is one host proposal. ok is true or false. reason is proposed, no_template, no_candidate, or rejected. The record also stores tier and payload. The printed line does not. Replay calls [`WyrdGenerator.propose`](WyrdGenerator.md#propose). Load does not log one. A background generate unit does not log gen_propose. A gen_reject line is one validator failure. rule is exists, place, protected, bounds, assumes, or known. attempt is 0 on the first try. Replay skips it; propose regenerates it. Load does not log one. A gen_cap line is one template `max_active` excluded. Replay skips it. A gen_expire line is one generated instance abandoned because `expires:` elapsed. reason is timeout. Replay skips it; the replayed tick regenerates it. A gen_accept line is one accept. reason is created, refused, stale, accepted, or unknown. instance is the id, or empty. Replay calls [`WyrdGenerator.accept`](WyrdGenerator.md#accept). Load does not log one. The other gen lines are regenerated by propose or accept and compared by [`diff`](#diff). The prefix matches key, instance, or template. An object or item cast stores the slot kind as `slot_kind`. The printed line labels that field `kind`. `kind` on the record stays the event name (`cast` or `slot_state`). An item cast also stores `owner` when it was recorded. A social_cache line is one cache invalidation, miss, or hit. event is invalidate, miss, or hit. cache is axis, disposition, reputation, path, or the invalidation reason, and the printed line labels it kind. who is the source or subject. key is the other party, or the reason on an invalidation. path is the axis name or kind list. bucket is the time bucket. entries is how many entries were dropped. Reads and hits log only when tracing is on. Replay skips the line. Load does not log one. A scheduler line is one queue's units for a game tick, or one enqueued item. key and queue are waits, rumor, publish, cache_refresh, generate, or frame. units is the work done. carry is the unfinished count. A frame line is the debug soft warning: us is the measured time and threshold is the config. The default threshold is 2000 microseconds (2 ms). 0 disables the line. The warning does not change the work. It sets timing true, because us and the row's presence depend on wall-clock time. [`diff`](#diff) leaves out every row with timing true and compares every other row exactly. The row stays in the trace. Replay skips the line. It is not saved. A rumor_hop line is one precise hop: deed, speaker, listener, and hop. path is the policy id. who is the listener. key is the fact. taken is true when the seeded roll offers the hop. reason is pass, chance, or coarse. A rumor_adopt line is that offer's credibility check. accepted is true when believed/<listener> was written. Replay skips both. Load does not log them. A rumor_reach line is one coarse rise: deed, place, policy, level, and fact. who is the place. path is the policy id. A rumor_materialize line is one seeded draw for an NPC in that place. who is the listener. path is the policy id. accepted is true when believed/<listener> was written. Replay skips both. Load does not log them. A rumor_mutate line is one field of an accepted hop or materialize. who is the listener. path is the policy id. key is the field. kept is true when the seeded roll retains the value. result is keep, mutate, or drop. Replay skips it. Load does not log it. A publish line is one frozen issue. path is the document id. key and issue are the copy id. who is the group. deeds is the deed count. Replay skips it. Load does not log it. A text_translate line is one rendered line that used or rejected a translated template. key is the line id. path is the locale. ok is true when the translation was used. reason is translated, placeholder_mismatch, compile_error, or frozen_shape. Replay skips it. Load does not log one. A storylet_index line is one index read. scope is the scope text. speaker is the query speaker. key is the scope id, empty for a bark. ids is the count returned before secrecy, when, and cooldown. Replay skips it. Load does not log one. A null index does not log one.
