# WyrdGenerator
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Unsaved story-pressure queue.

[`offer`](#offer) appends a host offer, or replaces tier and payload when the same source and key are already queued. Deed hooks use [`queue_deed`](#queue_deed). The queue is not saved. [`generate_handler`](#generate_handler) is the runtime's handler.
