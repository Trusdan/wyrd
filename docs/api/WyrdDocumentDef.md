# WyrdDocumentDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdStmtSpan`

One compiled document.

A header with `publishes_by`, `every`, or `delay` is the periodic issue. [`period_minutes`](#period_minutes) and [`delay_minutes`](#delay_minutes) are game minutes. [`fragments`](#fragments) are the slant rules, in source order. The first fragment whose condition is true supplies `slant`. A header without those words is a readable document. [`mode`](#mode) is `live` or `frozen`, and [`period_minutes`](#period_minutes) stays 0 so the publish queue skips it. [`pages`](#pages) hold paragraph prose. [`on_first_read`](#on_first_read) and [`on_read`](#on_read) are the read effects. Read flags are not stored on this def and are not facts.
