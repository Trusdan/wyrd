# WyrdFactStore
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Stored facts, resolver cache, and perspectives.

World values are `Object.set` and `Object.get`, implemented here as `_set` and `_get`. Godot already owns those names, so a perspective argument cannot be added and `set` cannot return a bool. [`set_in`](#set_in) and [`get_in`](#get_in) take `world`, `known/<agent>`, `believed/<agent>`, or `held/<group>`. Only schema-declared stored facts can be learned, believed, or held. A missing fact reads as null. Conditions treat that as false.  [`fact_changed`](#fact_changed) fires only for prefixes passed to [`subscribe`](#subscribe). Callables on this object are the runtime's hooks. They are not saved.
