# WyrdTemplateDef
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `WyrdQuestDef`

One compiled quest template. Instances are `<id>#<n>`.

The body reuses quest slots, `on_empty`, `on_missing_stage`, `requires`, and stages. There is no `start`. [`when_cond`](#when_cond) is a storylet condition. [`assumes`](#assumes) is a wait condition. A bare slot or param name in an entity argument, or compared with an entity, compiles as `holder(<name>)`. An empty tier overlaps every tier. A range overlaps every tier. Two single names overlap only when they are equal. [`weight`](#weight) does not break a tie.
