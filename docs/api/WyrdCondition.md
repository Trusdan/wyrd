# WyrdCondition
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Compiles one condition or value expression to plain data.

[`CONTEXT_STORYLET`](#context_storylet) allows `chance`. [`CONTEXT_WAIT`](#context_wait) rejects it, and rejects resolved facts invalidated `per_query` or not at all (`E_WAIT_RESOLVER_MODE`). `allow_spatial` lets a wait name `nearby`, `can_perceive`, or `can_reach`. `event_fields` types `event.<field>`, or `deed.<field>` when `binding_prefix` is `deed`. `bindings` types a bare name, such as `candidate` in a role eligibility condition. `minutes_per_day` defaults to 1440 until a calendar resource exists. `expected` is used when `require_bool` is false, so a value expression can be checked against a fact or argument type. Existing callers keep the bool default.
