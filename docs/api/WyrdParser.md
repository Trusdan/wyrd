# WyrdParser
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Block parser for grammar v1, plus the checked `facts` and draft `events` and `role` blocks.

`quest`, `scene`, and `storylet` bodies are a generic statement-line tree. Their statements are not interpreted here. `await_host` stays a line in that tree; the statement compiler reads the screen id and fields.
