# WyrdSecrecyLint
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Compile-time secrecy check. Runs only when `check --tiers` passes a list.

`W_SECRECY_LEAK` warns when visible text at a lower tier interpolates a stored fact that every writer which can run sets at a higher tier. An empty tier is the lowest. A name missing from the list is locked: that text is skipped, and that writer is ignored. `{if}` conditions are not values.
