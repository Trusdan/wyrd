# WyrdSaveMigrate
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Rewrites saved ids through a pack's resolved `was:` tables.

[`apply_aliases`](#apply_aliases) is pure. It does not change `doc` or `aliases`, and it does not read a runtime, a config, a clock, or an RNG. The same inputs always return the same document, rows, and diagnostics. Empty tables return `doc` itself and no rows. A second call on the returned document adds no rows: chains are already resolved, so one lookup is the final id.  The return value is `doc` (a rewritten copy, or `doc` when nothing changed), `rows`, and `diagnostics`. Each row matches [`WyrdLoadReport.add_row`](WyrdLoadReport.md#add_row): `kind` is `alias`, `id` is `stage:<quest row id>`, `trail:<quest row id>:<old>`, `role:<old>`, `document:<old>`, or `verb:<old>`, `from` is the old id, and `to` is the final id. A rewrite row has an empty `code`. A dropped old id has `W_SAVE_ALIAS`. `count` is how many saved entries were rewritten or dropped. Each diagnostic is `code`, `message`, and `severity` (`warning`).

### `resolve_stages`

**Experimental**

```gdscript
static func resolve_stages(doc: Dictionary, content: WyrdContent) -> Dictionary
```

Moves a quest off a stage the content no longer has, and restarts a region whose leaf is gone. Pure: it does not change `doc` or `content`, and it does not read a runtime, a config, a clock, or an RNG. A refused load never calls it. A second call on the returned document adds no rows.  The new stage is `on_missing_stage`, else the last `trail` entry that is still a stage, else the first declared stage. The row arrives entered, with entry steps already counted, so nothing runs. Each move adds one `missing_stage` row and one `W_SAVE_STAGE` warning.
