# WyrdSocial
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Relationship baselines, deed axes, and disposition.

Kinds and baselines are stored. Axes add a configured verb delta times the deed's decayed weight. A deed counts for `axis(observer, subject)` when `subject` did it and `observer` was the target or a witness. A kind the observer holds toward the subject multiplies that delta by [`WyrdConfig.kind_scale`](WyrdConfig.md#kind_scale). Several matching kinds multiply. The baseline is not scaled. The default disposition is `disposition_default + affinity / 2`, clamped to 0..100. A host may [`register_formula`](#register_formula); the callable receives `(a, b, axes)` and is not saved. [`reputation`](#reputation) is the mean disposition of a group's members toward the subject. It is derived, not saved. Axes, disposition, reputation, and [`path_exists`](#path_exists) are cached for the current time bucket. [`set_cache`](#set_cache) false recomputes and does not store. A deed, relationship, membership, config, or bucket change drops the entries. An invalidation drops every entry and queues no `cache_refresh` unit. Entries refill on read. The cache is not saved.

### `reputation`

**Experimental**

```gdscript
func reputation(subject: StringName, group: StringName) -> float
```

Mean disposition of `group`'s members toward `subject`. The subject is skipped. Duplicate members count once. No members returns 0. The mean shares the social cache. The stamp is checked once per call, then each member's axis and disposition entries are filled with the same keys a direct read would store. Membership inside a host is read again only after [`invalidate_members`](#invalidate_members). [`WyrdRuntime.invalidate_groups`](WyrdRuntime.md#invalidate_groups) is the host signal.

### `path_exists`

**Experimental**

```gdscript
func path_exists(source: StringName, target: StringName, kinds: PackedStringArray, max_hops: int) -> bool
```

True when `target` is reachable from `source` in at most `max_hops` directed steps. A step may use any kind in `kinds`. `source` equals `target` when `max_hops` is at least 0.
