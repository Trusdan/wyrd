# WyrdStoryletIndex
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Sorted storylet ids for one pack, grouped by scope and speaker.

Built at link. Not a save field. Each id is stored once, in the bucket of the last definition of that id. A bark row uses an empty scope id, because a bark query ignores the scope id. Speaker `any` is its own bucket. A concrete query merges that speaker's bucket with the `any` bucket. An empty query speaker, or `any`, merges every speaker bucket for the scope. `Any` is a concrete speaker. [`text_bytes`](#text_bytes) is the UTF-8 size of the stored ids plus the bucket keys.
