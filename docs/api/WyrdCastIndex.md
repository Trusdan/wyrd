# WyrdCastIndex
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Derived candidate cache for hosts that report world changes. Not saved.

A base list is one [`WyrdWorldAdapter.candidates`](WyrdWorldAdapter.md#candidates) answer, deduped and sorted the same way as a full scan. A local list is the entities in that answer that pass a plan's local clauses. [`invalidate`](#invalidate) with ids marks every base list stale and drops those ids' cached results. The next use asks the host once per filter and diffs. An empty id list drops everything.
