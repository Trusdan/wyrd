# WyrdEvents
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Host entry for `Wyrd.events.emit`.

[`emit`](#emit) asks the runtime to type-check the payload, drop `on_event` caches, and re-check dirty conditions before it returns. [`begin_batch`](#begin_batch) coalesces those re-checks until the matching [`end_batch`](#end_batch). The ring buffer is for the playtest. It is not saved.
