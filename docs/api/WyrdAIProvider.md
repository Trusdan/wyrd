# WyrdAIProvider
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Host hook for an AI answer.

[`request`](#request) returns at once. The answer comes later, on the main thread, through [`WyrdAIRequest.reply`](WyrdAIRequest.md#reply) or [`WyrdAI.deliver`](WyrdAI.md#deliver). A provider never waits. The core has no network code. Unimplemented methods `push_error` and return a typed fallback.
