# WyrdLoadReport
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Stable**

Inherits: `RefCounted`

Result of loading a content manifest. Named in the save/load design.

[`ok`](#ok) is false when the compiler reported any error. Warnings stay in [`diagnostics`](#diagnostics) and do not refuse the load. [`manifest_hash`](#manifest_hash) is 0 when the load was refused. [`rows`](#rows) is empty for a content load. [`WyrdRuntime.load_state`](WyrdRuntime.md#load_state) adds one row per diagnostic, plus `kept` rows for saved ids the pack does not declare and the runtime keeps. Each row has `kind`, `id`, `from`, `to`, `count`, and `code`. Unused text is empty and an unused count is 0. Rows are sorted by kind, then id, then code.
