# WyrdSave
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

JSON-safe snapshot of one runtime. Schema 4 adds `generator` when a generated quest instance exists. An optional `ai` key holds validated cache rows when [`WyrdConfig.ai_save_cache`](WyrdConfig.md#ai_save_cache) is true and the cache is not empty; an older loader ignores it, a malformed key warns `W_SAVE_AI` and is ignored, and open requests are not saved. Schema 3 stores in-flight rumors, publish counters, and scheduler carry in `flight` when any of that exists. Schema 2 fills belief bags. A schema 2 document has no `flight` key and loads with empty in-flight state. Evidence deadlines, when any exist, ride in `facts.evidence`. Line-set draw state and director `seen` / `last_minute`, when any of that exists, ride in `storylets`. An unknown storylet id is kept in that bag and ignored. Bark speaker clocks, when any exist, ride in `bark_speakers`. An unknown speaker id is kept. A missing `bark_speakers` key clears those clocks and leaves storylet rows. Sequence progress, when any exists, rides in `sequences`. An unknown sequence id is kept. A missing `sequences` key clears that bag only. Unlocked topic ids, when any exist, ride in `topics` as a sorted list. An unknown id is kept. A missing `topics` key clears that set. Read flags and frozen copies, when any exist, ride in `documents`. Read flags are `(reader, doc)` pairs, not stored facts. A missing `documents` key clears both lists. Unknown ids are kept and ignored. Quest region leaves ride inside the quest row and are omitted when empty. An older loader ignores those keys. The unlocked secrecy name is an ordinary world fact. The document has no secrecy key.

[`migrations`](#migrations) is the ordered table from schema N to N+1. Step 0 fills `facts.believed` and `facts.held`. Step 1 leaves the document as it is. Step 2 adds an empty `generator` object when the key is missing. It does not write `schema_version` and it does not change `quests`. The file's own version stays in place so `_import_flight` still compares it with [`FLIGHT_SINCE_SCHEMA`](#flight_since_schema). A schema 2 file has no `flight` key: token queues and the slice come back empty, and the dirty waits stay armed. A save from schema 3 on omits `flight` only when that set was empty, so load clears the dirty waits. [`FLIGHT_SINCE_SCHEMA`](#flight_since_schema) pins that rule, and a later schema bump leaves it in place. `generator` holds instance counters and casts. It is omitted when there are no counters. A generated quest row adds `template` and `n`. A missing template keeps those rows, entries, and counters, and warns `W_SAVE_TEMPLATE`. Schema 5 is refused. 64-bit values are lowercase hex. A scene must be closed. A manifest hash mismatch warns in a debug build and is silent in a release. After the shape check, [WyrdSaveMigrate] rewrites quest stages, role ids, deed verbs, and document ids through the content's alias tables. Empty tables leave the document unchanged. An old id whose new id is also saved is dropped with `W_SAVE_ALIAS`. The load stays ok. The import phase does not refuse.
