# WyrdDirector
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Picks one storylet for a scope and speaker.

`speaker: any` is a wildcard. A specific query speaker matches that speaker and `any`. An empty query speaker, or `any`, matches every storylet in the scope. `Any` is not the wildcard. Exact speaker is a filter, not a rank key.  Filters are scope, speaker, secrecy, `when`, then cooldown. A storylet whose secrecy name sits above the unlocked tier is dropped before ranking. An empty secrecy name stays visible. Each dropped candidate logs one `secrecy` line when tracing is on. Cooldown is hard: a storylet is eligible when it has never been selected, its cooldown is 0, or the minutes since `last_minute` are at least [`WyrdStoryletDef.cooldown_minutes`](WyrdStoryletDef.md#cooldown_minutes). If every match is cooling, the query has no winner.  A bark also consults [`WyrdStoryletDef.speaker_cooldown_minutes`](WyrdStoryletDef.md#speaker_cooldown_minutes). The clock key is the query speaker when that name is concrete, otherwise the storylet speaker when that name is concrete. `any` and an empty name are not concrete and do not start a clock. Topic, event, and beat queries ignore it. A win with a positive cooldown stores that duration for the key. A candidate is cooling while `now - last` is still below the stored duration.  Ranking, highest first: priority, specificity, weight, then fewer times seen, then the older `last_minute`. Never selected sorts as older than any selection. Generics stay in this pool at specificity 0. A higher priority beats a more specific storylet.  Remaining ties are sorted by id. [`WyrdRng.for_decision`](WyrdRng.md#for_decision) on [`STREAM`](#stream) breaks them. The decision key is the scope text and the query speaker. The time bucket is the current game minute. A bark query ignores `scope_id` for both the match and that key. A unique winner does not roll.  A win records the selection, then draws the body. [`WyrdStoryletDeck.draw`](WyrdStoryletDeck.md#draw) alone does not record one. Candidates in the trace are the count after the filters. When [`WyrdConfig.trace_director`](WyrdConfig.md#trace_director) is true and tracing is on, each scope-and-speaker match logs one `director_candidate` line before that summary. The line carries the score and the first failing clause.  The id list comes from the link-time storylet index: one sorted list per scope kind, scope id, and speaker, plus the `any` speaker bucket. A bark query still runs inside this call. A null index scans every storylet.
