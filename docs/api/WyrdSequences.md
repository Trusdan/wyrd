# WyrdSequences
Generated by tools/gen_api_docs.sh from the ## doc comments. Do not edit by hand.

**Experimental**

Inherits: `RefCounted`

Timed event sequences. Partial progress is saved. Not a quest stage.

`ordered` matches steps in source order. `any` with one step counts that step up to `m`. `any` with several steps counts each step once. The window is game minutes and includes the minute it closes. A finished sequence stays finished until its reset. A reset event is handled before a step on that same emit, so the reset does not also count.
