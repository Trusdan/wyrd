Playtest commands for one runtime.

The verbs are the §3.3 set: set a fact; kill, vacate, or replace a role holder; advance time; fire an event; run a scene in a text UI. `advance` and `choose` walk that text UI. `quit` and a blank line are prompt control. They are not commands. A release export must exclude [`RELEASE_EXCLUDE`](#release_exclude). The runtime does not reference this script, so the exclude removes it from the PCK.
