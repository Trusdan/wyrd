### `import_rows`

**Experimental**

```gdscript
func import_rows(rows: Array, cap: int) -> int
```

Replaces the contents. Returns how many rows were skipped. A row is skipped when it is not a [Dictionary], when `k` is not 16 lowercase hex digits, or when `t` fails [`WyrdAIValidator.safe_text`](WyrdAIValidator.md#safe_text). Rows are applied oldest first, then trimmed to `cap`, keeping the newest.
