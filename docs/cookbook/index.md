# Cookbook

Six short recipes. Each one is a problem, the content that states it, the host side when there is one, and what to test. The language rules stay in the [language reference](../language.md). The calls stay in the [API reference](../api/index.md).

- [Role fallbacks](role-fallbacks.md): empty, departed, and replaced holders.
- [Topics](topics.md): unlocking a topic and asking it.
- [Barks](barks.md): a nearby line with a speaker cooldown.
- [Social and reputation](social-and-reputation.md): deeds, decay, disposition, and baselines.
- [Epilogues](epilogues.md): journal text, deed totals, and a host-called stitch.
- [Migration](migration.md): `was:` aliases and the load report.
