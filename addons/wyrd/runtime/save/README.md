# save

`WyrdSave.capture` / `apply` implement `WyrdRuntime.save_state` and `load_state`.

Schema version is 2. `WyrdSave.migrations` has one step. It fills `facts.believed` and `facts.held` when a schema 1 save is missing them. A version below 1, or a version this table cannot reach, is `E_SAVE_VERSION`. Load content first.

The document holds pack id and manifest hash, language version, world, known, believed, and held facts, the deed log, relationship baselines and kinds, role bindings, definitions, frozen casts, and told sets, quest status, stage, outcomes, slots, host-step fields, frozen journal rows, and region leaves when a stage has them, effect provenance, play minutes, the game seed, and each named RNG stream's `to_state()`. `sequences`, when present, holds partial or finished sequence rows (`count`, `done`, and `started` or `matched` when set). A missing `sequences` key clears that bag only. An unknown sequence id is kept. Believed and held bags are sparse: an agent or group appears only when it has keys. `storylets`, when present, holds line-set draw rows and director `seen` / `last_minute`. `bark_speakers`, when present, holds bark speaker clocks (`cooldown` and `last_minute`). A missing `bark_speakers` key clears those clocks and leaves storylet rows. `why-not` reads those bags and does not add a key. The unlocked secrecy name is an ordinary world fact. Schema stays 2 and the save has no secrecy key. `WyrdConfig.secrecy_tiers`, `WyrdConfig.secrecy_fact`, and `WyrdConfig.trace_director` are host knobs and are not saved. An id the pack does not declare is kept and ignored. An unknown speaker id is kept.

In-flight rumor tokens are dropped with the other scheduler queues. The rumor claim table, coarse reach rows, and materialize draws are not save keys. Schema stays 2. Load drops them and does not continue a rumor or a reach rise. Beliefs already written stay in `facts`. A later ask does not materialize from a dropped row. Schema 3 will persist reach. Load does not log `rumor_hop`, `rumor_adopt`, `rumor_reach`, or `rumor_materialize`.

The inspector snapshot is not a save key. Load does not log `debug_snapshot`. Deed compaction removes provenance rows whose facts are not marked `recap`. That still uses the `provenance` key. Schema stays 2. Load does not log `choice_summary`. Coverage counts are not a save key. Load does not log `coverage`. A console `set` stores provenance with scene `console` and choice `set` on the existing `provenance` key. Schema stays 2. Load does not log `console`. 64-bit values are lowercase hex so `JSON.stringify` does not round them. Other integers are coerced back to int on load. A scene must be closed. A hash mismatch adds `W_SAVE_MANIFEST` when `OS.is_debug_build()` is true and stays silent in a release. The load still applies.
