# adapters

Typed adapter base classes a host implements. Unimplemented methods `push_error` and return a typed fallback. The fake host in `tests/fake_host` overrides them. `WyrdTimeAdapter.season` answers a `time.season` resolver. `WyrdSpatialAdapter.witnesses_of` answers `witnesses: auto` and defaults to an empty list. `WyrdWorldAdapter.members` answers `faction_assigns`. `WyrdWorldAdapter.candidates` answers a `cast` slot; an empty filter asks for every entity the host will offer. `WyrdElectionAdapter.start_election` is the host hook for `election` succession. The fake host does not register one.
